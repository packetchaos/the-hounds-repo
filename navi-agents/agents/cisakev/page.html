🛡️ CISA KEV Tagging

Laelaps finds the Known Exploited Vulnerabilities on your assets and tags those assets. It joins navi.db to CISA's KEV catalog by CVE, so you see each KEV's CISA remediation due date, ransomware use and vendor. Tags: CISA KEV : Vulnerable, by date added CISA KEV : <Mon> - <DD> - <YYYY>, by due date CISA KEV Due : <YYYY-MM-DD>, and CISA KEV : Ransomware. All gated; tracked in the Tagging log.

Human approval — external download

Due dates, ransomware use and vendor names come from CISA's KEV catalog, downloaded before the analysis runs. Review and approve.

✨ Ask — hunt CISA KEV in plain English

Turn a question into a read-only SQL over navi.db / tags — e.g. "assets with a CISA KEV and ACR over 7", "KEV added in 2025 by hostname", "which assets already carry a CISA KEV tag".

The KEV hunt needs a language model. Set an API key on Settings to enable plain-English → SQL — everything else here works without it.

Remediation due dates

CISA sets a remediation due date for every KEV. Bars show how many of your assets have a KEV due that month: overdue (past due, still open) vs due later. Click a bar to select that month's due dates. Tag the assets behind each due date as CISA KEV Due : <YYYY-MM-DD>. The date sorts and filters in Tenable, so “due before today” is a simple filter.
