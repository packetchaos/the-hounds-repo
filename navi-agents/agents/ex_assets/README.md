# Asset Explorer (Bloodhound)

Search navi.db assets by hostname, IP, OS or network. Read-only search over navi.db via the UI.

Actions: `search {q}` → rows · `evidence {key}` (the asset set behind an On the Scent number, stored
server-side) · `drill` (page / search that set) · `export` (that set as CSV).
The ✨ Ask box turns a plain-English question into one read-only SQL query on `assets` (needs a model).
