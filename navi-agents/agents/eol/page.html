⏏️ EOL / Unsupported software tagging

Charon finds the assets running Unsupported or End-of-Life software. It matches lifecycle text in plugin names, so new EOL plugins are picked up automatically. It tags those assets by lifecycle group Lifecycle : Unsupported | End of Life (navi tag --name) and by the date the vendor ended support Lifecycle EOL : <YYYY-MM-DD> (navi tag --plugin). The end-of-life date is read from the plugin output. All writes are gated and tracked in the Tagging log.
