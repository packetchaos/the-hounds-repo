Dashboard Builder

Describe a view in plain English. The model writes one read-only SELECT over navi.db and renders it as KPI tiles, a bar chart, or a table — a build-your-own dashboard for anything we didn't ship a page for. Read-only: nothing is ever written.

The Dashboard Builder needs a language model to turn your request into SQL. Set ANTHROPIC_API_KEY on the server and reload to enable it.
