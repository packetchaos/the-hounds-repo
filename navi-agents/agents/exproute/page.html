✨ Ask — describe the ownership mapping

Or set a disposition instead of an owner — "ignore the ICMP route, accept the OpenSSL route, all Windows Office routes are mitigated." That tags Owner : <route>: Ignored / Accepted / Mitigated so it drops off the gap list. Disposition phrases work even without a model key.
