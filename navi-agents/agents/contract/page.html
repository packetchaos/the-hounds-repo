Schedule & defaults

Per-agent policy

Leave a policy blank to fall back to the risk-weighted top-N. Examples: IoT → "tag all IoT but not Dell or Intel — those are laptops"; Custom apps → "only /opt apps and jenkins matter"; Exposure routes → "payment routes → VM Team; docker → Custom Apps".

ACR changes

navi never changes the ACR of an asset tagged NO : UPDATE — 📋 Plan shows, per rule, how many assets change and how many are protected. Every change is recorded per asset in the ACR log.

🗑️ Tag removal (Garmr)

When armed, the contract removes these tags first, forces a pause, runs navi update, then re-runs the tagging workflow. Add tags from the Tag Removal agent, or type them below.

📧 Run summary email (Gabriel)

Every cycle, Gabriel emails a summary of what the contract did — tags queued, ACR applied, tags removed, and any Alert Raven alerts that fired. On by default; uncheck to stop getting an email each run. Sending is still gated by NAVI_EMAIL, so a gated inbox just records what would have gone out.
