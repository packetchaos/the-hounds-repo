# Route Explorer (Wolfhound)

Application routes from navi.db (vuln_route) — search by app name or type. Read-only search over navi.db via the UI.

Actions: `search {q}` → rows · `count` · `tag` (gated tag of the assets on a route).
The ✨ Ask box turns a plain-English question into one read-only SQL query on `vuln_route` (needs a model).
