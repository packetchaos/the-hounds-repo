Mimir

📦 Software analyzer

Mines the software table (reconciled with the cpes inventory) to find version sprawl — the same product at many versions — plus most-deployed, standardized vs fragmented, and single-install software. Check lifecycle (endoflife.date), flag crown jewels, and rank a risk leaderboard. Tag any product or version (gated).

✨ Ask — query the software inventory

Plain-English question → one read-only SELECT over software joined to assets / vulns. e.g. "openssl versions on assets with ACR over 8" · "products on hosts that have a critical CVE".

Press ▶ Run crown jewels (or ▶ Run all) to flag assets running business-critical software — databases, hypervisors, directory, PKI, backup, security tooling — with a suggested ACR.

Press ▶ Run risk leaderboard (or ▶ Run all) to rank products by the KEV / critical findings that name them and the exposure on the hosts that run them.
