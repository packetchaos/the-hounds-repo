MITRE ATT&CK tagging

Tags assets with the ATT&CK impact of the vulnerabilities they carry. It fetches the ATT&CK→CVE mapping, finds the assets in navi.db whose findings cite each mapped CVE, and tags those assets Mitre : Primary Impact / Secondary Impact / Exploit Technique. The CVE is only the selector (navi tag-by-CVE); the tag lands on the assets. Writes are gated.
