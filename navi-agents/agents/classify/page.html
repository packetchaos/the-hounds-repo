📇 Asset Classification

📡 OS Signals

Two connected pies over the OS-ID plugin output (11936) — click an OS (Windows / Linux / macOS) to drill into its versions, then click a version to tag by that OS. Tagging auto-populates the classification pies above. Edit the tag name before writing if you like; writes are gated.

🤖 Describe the OS tagging

Plain English over the OS-ID plugin output (11936), which carries an OS type and a confidence %. Filter by confidence and OS, then write Asset Inventory : OS: <value> tags (gated). e.g. "tag all my assets by OS that has a confidence of over 75%" · "tag windows assets by OS with confidence ≥ 90" · "tag by OS family, high confidence". Works without a model key.
