🩺 Health checks read-only

Fixed read-only commands, packed into one SSH session per host, each bounded by a remote timeout. Hosts never contacted before have their SSH key trusted on first use (said in the preview).

Policy (checks + path): canary first stop after errors or % transport retries stop after failed logins (account lockout) Retries only when the host could not be reached before anything ran — never after an auth failure or a host-key problem.

🔑 Login test read-only

Runs id; sudo -n true: tells apart auth failed, unreachable, port closed, DNS, timeout and a CHANGED host key. One attempt per host (never retried).

🔎 Does this path exist? read-only

exists · type · size · owner · mode · mtime · sha256 (files ≤ 50 MB). The path is ONE shell-quoted argument; falls back to sudo -n (never prompts).
