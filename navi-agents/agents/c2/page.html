🐺 Command & Control

Amarok — troubleshoot and remediate Linux hosts over SSH via navi action push: built-in read-only checks, credential tests, “does this path exist?”, AI-assisted remediation plans, and free-form commands — on navi.db assets or any IP / hostname. Every remote command is triple-gated (writes + remote-exec opt-in + your confirm) and lands in the C2 command log (what ran where and when — never the reply).

⚙ Run options — canary, error threshold, retries
Canary first (one host, then the rest)

Retries happen only when the host could not be reached before anything ran — never after an auth failure (account lockout) or a host-key problem, never after a command ran. Remediation always stops on the first error.

🩺 Quick diagnostics

Built-in read-only checks — fixed commands, nothing installed or restarted, each bounded by a remote timeout, packed into one SSH session per host. Still remote execution: gated and confirmed. 🌐 Public IP .

🔑 Credential test

Logs in with the navi config ssh credentials and runs id; sudo -n true — one attempt per host (auth failures are never retried). Tells apart auth failed, unreachable, port closed, DNS, timeout and a changed host key (a security event — nothing runs). A NEW host's key is recorded here, so run this before strict-host-key changes.

🔎 Does this path exist?

exists · type · size · owner · permissions · mtime · sha256 (regular files ≤ 50 MB). The path is passed as ONE shell-quoted argument — characters like ; are part of the name, never a command. Falls back to sudo -n when unreadable (never prompts).

🛠 Remediation — plan → review → deploy

Tenable's own Solution and the plugin output in navi.db are the source of truth; the configured model (or, without one, deterministic package-manager templates) turns them into a strict JSON plan; a deterministic validator — not another model — allows only package installs/upgrades of the named package, systemctl restart/reload, and rm/chmod/chown on a path the source names, and rejects everything else with the reason. Deploy = canary first, stop on the first error, verify each step, strict host keys.
