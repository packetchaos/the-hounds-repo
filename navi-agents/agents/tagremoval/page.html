🗑️ Tag Removal

Garmr lists the tags in navi.db — the only ones navi can strip. Each removal runs navi enrich tag … -remove against the assets navi.db says carry it and shows in the Tagging log as a remove job. Tags that exist only in Tenable are listed separately in the compare below — they sit on assets navi.db doesn't hold, so they can't be removed from here. Send your picks to the AI Contract and it will remove them first, pause, refresh navi.db, then re-run the tagging workflow.

⚠ Removals only reach the assets in navi.db. navi's asset sync pulls assets seen in the last N days (90 by default) and never deletes the ones that age out or fall off licensing — so navi.db can hold assets Tenable no longer licenses, and Tenable can hold tagged assets navi.db never pulled. -remove strips from navi.db's view, so tags on assets outside it stay put. Keep navi.db current (assets sync), and if it has drifted, rebuild navi.db with the window you need.
