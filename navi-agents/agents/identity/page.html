Janus

🆔 Identity inventory

Discovers identities by content, not a memorized plugin list: plugin names and raw output, then the high-value enumerators (passwd 95928, SMB users 10860, non-expiring 83303, host SID 10859, SNMP 41028). Classifies Human / Service-NHI / Machine using external authorities (Microsoft well-known SIDs/RIDs, AD machine $ accounts, the Linux login.defs UID convention), flags the risky ones, and shows the coverage gap (hosts scanned without credentials). Tags the assets each identity lives on via navi tag --query; writes are gated and tracked in the Tagging log.

By class:

Account reuse

The same account name on five or more hosts. That is account reuse, not proof of a shared password: navi.db shows which accounts exist, not their passwords. Treat it as a lateral-movement path to check, not as a known shared password. The scan account (Nessus plugin 19506) is excluded, because its host count comes from scanning.
