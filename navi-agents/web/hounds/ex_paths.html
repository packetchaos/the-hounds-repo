The fastest hound — Greyhound runs down any filesystem path in your navi.db.

The Problem

The filesystem paths navi discovers on assets (vuln_paths) reveal where software actually lives — but pulling the ones that match a keyword shouldn't take a hand-written query.

What It Does

Greyhound is a read-only search over the filesystem paths (vuln_paths) discovered on assets. Query by path text to find where a file, package, or app appears across the estate.

Key Capabilities

  • Search by path text — one box over every discovered filesystem path in navi.db.
  • Paths from vuln_paths — the file-level view navi builds from your findings.
  • Instant local results — runs against the navi.db mirror.
  • Read-only by design — Greyhound only searches.

How It Works

Greyhound runs a read-only search over the vuln_paths table in your local navi.db and returns matching paths.

Who It's For

Analysts locating a file or package across hosts; owners looking up their paths; anyone exploring paths before assigning them.

Works Better With

Part of the Search Pack — and the paths it surfaces are what Atlas and Argus assign owners and app names to.
