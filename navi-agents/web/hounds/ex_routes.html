The pack hunter — Wolfhound follows every application route in your navi.db.

The Problem

The application routes navi derives (vuln_route) are where exposure concentrates by app — but pulling a specific app's routes means a query you'd rather not hand-write every time.

What It Does

Wolfhound is a read-only search over the application routes (vuln_route) in navi.db. Query by app name or vulnerability type to find the routes that matter.

Key Capabilities

  • Search by app name or vuln type — one box over every application route in navi.db.
  • Routes from vuln_route — the app-level view navi builds over your findings.
  • Instant local results — runs against the navi.db mirror.
  • Read-only by design — Wolfhound only searches.

How It Works

Wolfhound runs a read-only search over the vuln_route table in your local navi.db and returns matching application routes.

Who It's For

Analysts scoping an application's exposure; owners looking up their app's routes; anyone exploring routes before assigning them.
