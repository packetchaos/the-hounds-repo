The relentless tracker — Bloodhound sniffs out any asset in your navi.db in an instant.

The Problem

When you need one specific asset — by hostname, IP, operating system, or network — clicking through platform filters is slow. You want a direct search over everything navi already mirrors, without leaving the console.

What It Does

Bloodhound is a fast, read-only search over the assets in navi.db. Query by hostname, IP address, operating system, or network and get the matching assets back instantly — no writes, no waiting on the platform UI.

Key Capabilities

  • Search by hostname, IP, OS, or network — one box over the whole asset inventory in navi.db.
  • Instant local results — queries run in milliseconds against the navi.db mirror, not the platform API.
  • Read-only by design — Bloodhound only searches; it never changes anything.
  • A launch point — hand any hit to Argos for the full per-asset dossier.

How It Works

Bloodhound runs a read-only search over the assets table in your local navi.db and returns the matching rows.

Who It's For

Analysts who need to find a host fast; responders locating an asset by IP or name; anyone exploring the estate without waiting on the console.

Works Better With
